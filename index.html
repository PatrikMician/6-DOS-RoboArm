O Robotickém Rameni

Tento projekt představuje robotické rameno řízené mikrokontrolérem Arduino za použití PWM ovladače PCA9685, displeje a dvousměrových joysticků.

🎮 Ovládání

Lze ovládat analogovými joysticky i přes webové rozhraní v Pythonu (pyserial).

📺 Zobrazení

Displej LCD 16x2 I2C zobrazuje aktuální úhly serv 1 až 5 v reálném čase.

💾 Paměť

Ukládání výchozích nebo uložených pozic v EEPROM mikrokontroléru.

Jak složit robotické rameno

Zde je postup pro složení robotického ramene. Návod je rozdělen do jednoduchých kroků:

  1. Připravte všechny součásti a nářadí.
  2. Složte základní rám robotického ramene.
  3. Připojte serva a ovladače.
  4. Instalujte software a nakonfigurujte mikrokontrolér.

Pro složení rámu robota můžete použít i video návod:

Serva nebude možné připojit k PCA9685 přímo, protože nemají tak dlouhé dráty. Je třeba je prodloužit připájením dalšího vodiče.

Serva připojujeme k PCA9685 od kanálu 0 (od pinů k Arduinu).

Desku PCA9685 a displej do Arduina připojíme následovně:
GND: GND
VCC: 5V
SDA: A4
SCL: A5

Joysticky jsou připojené následovně:
Levý: VCC → 5V, GND → GND, VRx → A0, VRy → A1, SW → D2
Pravý: VCC → 5V, GND → GND, VRx → A2, VRy → A3, SW → D4

Jak ovládat robotické rameno (Manual)

Rameno je ovládáno dvěma dvousměrovými joysticky s integrovanými tlačítky:

🕹️ Levý Joystick

  • Pohyb Vlevo / Vpravo (Osa X): Ovládá Předloktí (Servo 3).
  • Pohyb Nahoru / Dolů (Osa Y): Ovládá Sklon kleští (Servo 2).
  • Stisk tlačítka (SW1): Otevírá a zavírá kleště (Servo 0).

🕹️ Pravý Joystick

  • Pohyb Vlevo / Vpravo (Osa X): Ovládá Otočnou základnu (Servo 5).
  • Pohyb Nahoru / Dolů (Osa Y): Ovládá Hlavní rameno / Výšku (Servo 4).
  • Stisk tlačítka (SW2): Přepíná režim natáčení kleští.

💡 Režim natáčení kleští (po stisku tlačítka na pravém joysticku)

Pokud stisknete tlačítko na pravém joysticku, přepne se osa X pravého joysticku na Otočení kleští (Servo 1). Dalším stiskem tlačítka se ovladač vrátí zpět k řízení hlavního ramene.

Webové ovládání Arduina

Ovládání ramene z webu běží v Pythonu (Flask + pyserial) přímo na tvém počítači, protože GitHub Pages Python nespouští. Postup:

  1. Stáhni si projekt z GitHubu (Code → Download ZIP) a rozbal ho.
  2. Nahraj hotovy_kod.ino do Arduina a nech ho připojené přes USB.
  3. V terminálu ve složce projektu spusť:
    pip install -r requirements.txt
    python app.py
  4. Otevři ovládací stránku: http://127.0.0.1:5000/ovladani

Odkaz funguje jen tehdy, když je app.py spuštěný. Bez Arduina si můžeš ovládání vyzkoušet v režimu SIMULACE.
